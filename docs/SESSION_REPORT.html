젠가 블록 6DOF 편차 추정: 진행 보고서

2. 목표와 전제

  • 목표: “n층 m번째 블록을 빼라” 명령 시, 그 블록이 기준 대비 얼마나 틀어졌는지(dx, dy, dz, roll, pitch, yaw)를 로봇에 전달.
  • 핵심 아이디어: 타워는 매번 정리해서 시작하므로 기준 자세는 하드코딩하고, 카메라로는 기준에서의 편차만 보정한다 (탐지 문제 → 보정 문제).
  • 물리적 제약: 블록은 아래층 위에 놓여 z·roll·pitch는 거의 변하지 않는다. 실제로 변하는 것은 긴 방향 밀림(dx), 옆 밀림(dy), 수평 회전(yaw). → roll/pitch/dz는 강한 사전값으로 붙잡고 검증용으로만 출력.

좌표 / 번호 규칙

  • 앞면 = 태그 id 0·1 띠 면. 위에서 봤을 때 시계방향으로 오른쪽(2·3), 뒤(4·5), 왼쪽(6·7).
  • n = 1(맨 아래) … 17. 홀수층은 앞에서 긴 면이 보이고 m=1이 가장 앞. 짝수층은 앞에서 끝면이 보이고 m=1이 왼쪽.
  • 타워 좌표계: 원점 = 중심축 & 1층 바닥, +x 오른쪽, +y 뒤쪽, +z 위.
  • 블록 좌표계 (결과 delta 기준): x = 긴 방향, y = 폭, z = 위. 홀수층 블록 +x = 타워 오른쪽, 짝수층 블록 +x = 타워 뒤쪽. 예: 짝수층 블록을 앞으로 빼면 dx 음수.

3. 진행 과정

M0. 카메라 연결

  1. venv 구성, pyorbbecsdk2 설치, USB udev 규칙 설치.
  2. 컬러 / color 정렬 depth 스트림 확인 (tools/stream_check.py).
  3. 왜곡 모델이 8계수 rational임을 발견 → 5계수만 쓰던 코드 수정.

M1-1. 태그 맵 캘리브레이션

타워를 한 바퀴 돌며 두 면의 태그가 동시에 보이는 모서리 뷰 43장을 자동 저장하고, 띠(태그 2개)를 강체로 보고 카메라 자세 + 면 자세를 번들 조정.

M1-2. 기준 타워 위치 맞추기

수평 위치·방향은 지그에 끼워진 타워이므로 네 띠 평면의 중심에서 계산. 높이는 정리된 타워 사진 20장에서 층 사이 어두운 틈과 모델 층 경계가 맞아떨어지는 1층 바닥 높이 z0와 블록 높이 h를 탐색.

결과값비고
1층 바닥 높이띠 중심 + 27.0 mm바닥에서 ≈ 50 mm = 실측 박스 높이와 일치
블록 높이22.36 mm공칭 23 mm로 두면 17층에서 약 11 mm 누적 오차
탐색 프로파일단일 피크한 층 어긋남 같은 모호성 없음

M2. 블록 6DOF 추정 + 실시간 도구

추정 파이프라인 (estimator.py)

  1. 태그로 카메라 자세 (대략, mm 단위 오차)
  2. 국소 보정: 위아래 층(n±1, n±2) 바깥 면을 depth에 맞춰 카메라 자세 보정 (목표 블록 중심 기준, 사전값 ±6 mm/±2°)
  3. 블록 fit: 보이는 면 depth(테두리 5 mm 제외) + 윤곽의 밝기 기울기 + roll/pitch/dz 사전값을 IRLS로 최소화, 면 법선 방향 오프셋은 depth만으로 재계산
  4. REL(위아래 층 대비) / ABS(기준 대비) 두 결과
  5. 보이는 면 종류별 실험 1σ 하한으로 신뢰도 부여

실시간 도구 (live_block.py)

  • 터미널 n m 입력 → 기준(초록)/추정(빨강) 윤곽 + ABS·REL 6DOF 표시
  • 최근 15개를 축별 가중 중앙값으로 합산 (yaw는 긴 옆면 시점이 주도)
  • 측정 프레임·depth·결과 자동 녹화 + label
  • ROS2: /jenga/block_pose, /jenga/block_nominal_pose, /jenga/block_delta(ABS), /jenga/block_delta_rel(REL)

5. 문제와 해결

#문제원인해결
1SDK가 카메라를 열지 못함USB udev 규칙 미설치규칙 복사 + udevadm 재로드
2왜곡 보정 값 이상 (k1 = −1.08)8계수 rational 모델인데 5계수만 사용OpenCV rational 8계수 사용
3박스 높이 5 cm라 큰 태그 불가지그 크기36 mm 태그 2개 띠 → 인쇄로 간격 고정, 정확도도 향상
4depth와 태그 모델이 면마다 ±5 mm 불일치먼 거리의 작은 태그 자세 오차 + depth 노이즈위아래 층 면으로 국소 보정
5국소 보정 발산 (10~250 mm)카메라 원점 기준 회전, 반복 패턴에 잘못 맞춤목표 블록 중심 기준, depth만 사용, 사전값 제한
6roll/pitch 50° 이상 튐Huber가 사전값 항까지 약화IRLS: robust 가중치는 데이터 항에만
7경계선 검출 실패틈 대비 약함, 각인/배경이 더 강함윤곽 법선 방향 밝기 기울기, 흐림→선명 2단계
8블록을 뺄수록 pitch 증가 (4~6°)튀어나온 끝면 위쪽 테두리 depth가 뒤 면과 섞임면 테두리 5 mm 제외 → 3.7° → 1.2°
9측정값이 실제의 70~80%(a) 경계선 항이 안쪽 선에 끌림 (b) 센서가 작은 단차를 뭉갬(a) 법선 오프셋은 depth만 (b) depth 1280×800 + Close Range High Accuracy → 10 mm가 9.8 mm로
10뒤에서 본 값이 크게 틀림 (yaw +10°)안쪽으로 들어간 끝면은 구멍 벽에 가려 depth 비대칭들어간 끝면 측정의 신뢰도 하향
11합산 시 엉뚱한 yaw가 섞임계산상 1σ가 실제보다 너무 작음보이는 면 종류별 실험 1σ 하한 + 축별 가중 중앙값
12위아래 층이 같이 밀리면 측정에서 사라짐국소 보정이 이웃 층을 기준으로 가정ABS / REL 분리: 태그 오차는 시점마다 달라 상쇄, 실제 이동은 남음

6. 층 높이별 정확도 · 개선 아이디어

구간REL (이웃 대비)ABS (기준 대비)이유
아래층 (2~5층)±1~2 mm±1 mm 수준태그와 가까워 카메라 자세 정확
중간층 (6~12층)±1 mm, ±1~2°±2~3 mm태그와 블록을 함께 담으려면 거리가 늘어남
위층 (13~17층)±1~2 mm, ±2°±4~7 mm40~45 cm로 물러나야 태그가 보임, 기준 층이 아래쪽에만

REL은 전 높이에서 안정적이고, ABS는 태그(맨 아래)와 블록 사이 거리에 비례해 나빠진다. 또 손으로 쌓은 “정리 상태”도 수 mm 수준으로 완벽하게 곧지 않다 (예: 8층 부근 약 3 mm 뒤쪽).

손 촬영 단계에서 (필요할 때만)

  • 기준 상태 재캡처 테이블: 시연 전 정리된 타워를 훑어 블록별 실제 위치를 0으로 저장
  • 중간 높이 기준점: 타워 옆 고정 스탠드에 태그 → 위층 ABS 개선
  • 가운데 블록 yaw: 앞/뒤 끝면의 옆 위치를 함께 사용 → ±1° 목표
  • 다중 프레임 공동 최적화: 여러 프레임의 점/경계를 한 번에 fit

로봇 장착 후 (M3)

  • 카메라 자세를 FK + hand-eye로 → ABS의 태그 오차 제거 (예상 1~2 mm)
  • 블록별 촬영 자세 계획: 바깥 블록은 모서리 방향, 가운데 블록은 빠져나오는 쪽 끝면
  • 마름모 배치로 양팔이 블록 양 끝을 동시에 관측 → yaw·dx 강화

7. 앞으로 할 일

  1. 로봇 쪽과 합의: 허용 오차(몇 mm / 몇 도까지 잡을 수 있나), 인터페이스(토픽 연속 발행 vs “n층 m번 재 줘” 서비스).
  2. M3 손목 장착 (마운트 3D 프린팅 후): hand-eye 캘리브레이션, FK 기반 카메라 자세, 촬영 자세 계획, 태그는 보조로 유지.
  3. 남은 확인: yaw 10 mm 재측정의 자로 잰 양 끝 값 비교, 홀수층 블록의 옆면 밀기 테스트, 가운데 블록 실제 회전 테스트 (필요 시).
